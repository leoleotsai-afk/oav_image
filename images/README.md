# 圖片庫資料夾

把要被搜尋的圖片放進這個資料夾（可有子資料夾，支援 `.jpg` `.jpeg` `.png`
`.bmp` `.gif` `.tif` `.tiff`）。

- **檔名請取有意義的名稱**（例如「紅色馬達.jpg」「軸承_SKF6205.png」），
  因為語音查詢是用辨識出來的文字比對檔名關鍵字。
- 放好圖片後執行 `bin\ImageSearch.exe`（開啟時會自動建立索引），或按介面上的
  「🔄 重建圖片索引」按鈕。
- 這個資料夾底下的實際圖片檔**不會被 git 追蹤**（見專案根目錄的
  `.gitignore`），只有這個 README 跟 `.gitkeep` 會進版控，避免私人/機密照片
  不小心被推上公開的 GitHub repo。如果你想把範例圖片一起公開，自行調整
  `.gitignore` 即可。
